Mes extensions Firefox
======================

Après ma grosse colère contre Firefox et ses développeurs pour avoir bazardé tout l’écosystème d’extensions XUL, je m’étais mis à utiliser Chromium. Ma colère reste intacte face à autant d’imbécilité, qui amène à ce qu’aujourd’hui le navigateur de la fondation Mozilla soit utilisé par un peu moins de de 3% des internautes, au dessous de Microsoft Edge. Puis, je suis revenu au bercail, non sans mal, du fait notamment des containers, qui permettent de mieux se protéger du tracking des marketeux et des GAFAM, des Xiti et Cie !

* * *

Les extensions Firefox indispensables
-------------------------------------

Les extensions que je vais vous présenter ci-dessous sont celles que j’utilise en permanence sous Firefox Quantum. Il s’agit, par ordre alphabétique de :

uBlock Origin, pour le blocage des publicités et du tracking, la désactivation de l’audit de liens (prise en charge des filtres esthétiques comme AdBlock Plus) ;
Cookie AutoDelete, pour la destruction des cookies à la fermeture des onglets ;
I still don’t care about cookies, une extension pour ne pas avoir à confirmer la gestion des cookies dans les sites que vous visitez ;
CSS Exfil Protection, pour se prémunir du vol de données via les feuilles de style CSS ;
DecentralEyes, pour éviter le pistage via les API fournies par les GAFAM qui jonchent nos sites Web ;
ClearURLs, pour la réécriture d’urls afin d’éviter le tracking ;
Select Context Search, pour faire une recherche à partir de la sélection d’un mot d’une page ;
LiveMarks, pour afficher les liens des flux RSS dans les pages visitées depuis Firefox 64 ;
Page Saver WE, pour les copies d’écran des pages visitées ;
Containerise, pour une simplification de la gestion des containers, permettant d’ajouter des domaines à vos containers ;
Close same domain tabs.

Les extensions Firefox utiles
-----------------------------

J’utilise également de manière occasionnelle les extensions suivantes :

WebGL Fingerprint Defender, pour se prémunir de la collecte de données à partir de l’utilisation du moteur graphique WebGL ;
Canvas Fingerprint Defender, pour se prémunir de la technique de prise d’empreintes par du code HTML5 ;
Firefox Multi-Account Containers, pour la création des containers ;
Just Read, pour nettoyer les pages de leurs contenus inutiles ;
Open link in new tab, pour ouvrir de nouveaux onglets en cliquant sur des liens hypertextes ;
Joplin Web Clipper, pour envoyer vos contenus vers l’outil de prise de notes Joplin ;
Temporary Containers, pour étanchéifier vos données personnelles de navigation et permettre de se connecter dans des onglets différents à des comptes Twitter, Facebook ou Gmail différents ;
HTTP Header Live, pour visualiser les émissions et réceptions d’entêtes HTTP/HTTPS ;
Lightbeam, pour la mise en évidence du tracking perpétré par les marketeux ;
Link Gopher, pour aspirer tous les liens d’une page ;
Load Time, pour mesurer le temps de chargement des pages ;
PageTimer, pour mesurer également le temps de chargement des pages ;
Privacy Badger, une alternative à uBlock Origin, pour bloquer rapidement les contenus publicitaires et les pisteurs;
ColorZilla, pour capturer les couleurs utilisées dans une page Web ;
Measure-It, pour mesurer la distance entre deux points dans la page ;
EPUBReader, pour lire les fichiers au format ePub ;
Simple Ping Blocker, pour vous éviter l’audit de liens (inclus dans uBlock Origin) ;
CanvasBlocker, pour le blocage des techniques d’empreinte Canvas notamment utilisées par Facebook (devenu natif depuis Firefox 67.0) ;
Redirector, si vous voulez réécrire vous-même les URLs par des expressions régulières ;
InformEnter+, pour mémoriser les expressions utilisées dans vos formulaires ;
User-Agent Switcher, pour notamment publier à partir de Firefox sur Instagram ;
Invidition, pour contourner le tracking perpétré dans Youtube ;
Disable Polymer, si vous persistez à utiliser Youtube ;
Cookiebro, pour bloquer les cookies par domaine ;
Copy All Tab Urls, pour collecter toutes les adresses des pages ouvertes ;
OneTab, pour sauvegarder et restaurer les pages mémorisées dans la fenêtre de l’extension ;
Mailveloppe, pour chiffrer et déchiffrer les messages utilisant PGP ou GPG ;
Font Fingerprint Defender, pour se prémunir de la prise d’empreintes en ce qui concerne les polices utilisées ;
What Runs, pour connaître les technologies utilisées par le site visité ;
Wappalyzer (idem à What Runs) ;
Ressurect page, pour accéder aux contenus de pages offline ;
FoxReplace, pour bidouiller le code de la page afin d’en modifier le comportement ;
iMacros, pour concevoir des automates dans le navigateur ;
Tampermonkey, pour exécuter des scripts Javascript personnalisés ;
SingleFile, pour sauvegarder une page dans un seul fichier ;
FeedBro, en tant que lecteur RSS ;
Video DownloadHelper pour télécharger les vidéos Flash à partir de Youtube et de Dailymotion ;
Brief, lecteur de flux RSS ;
SimilarWeb, pour trouver des sites similaires à ceux sur lesquels vous surfez.
